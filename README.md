## Getting Started

### Prerequisites

Install Python 3 on your system.

### Clone the Repository

```bash
git clone https://github.com/Ankita9919/python-dsa-practice.git
cd python-dsa-practice
```

### Run a Solution

```bash
python bit_manipulation/xor_swap.py
```

Replace the file path with the solution you want to execute.
